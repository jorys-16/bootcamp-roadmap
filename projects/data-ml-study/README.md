# Data and ML Study

A small data-science project (Month 6): pick a real dataset that interests you, clean it, explore it, train a model, and write an honest evaluation.

## Phases
- **Week 22:** Pick dataset (Kaggle, NYC Open Data, or data.gov); clean and explore with pandas.
- **Week 23:** Train and evaluate a scikit-learn model; metrics and error analysis.
- **Week 24:** Optional LLM feature — e.g., summarize the dataset or generate insights via an API.

## Structure
```
data-ml-study/
  data/raw/        (never edited; add data source + license in a README)
  notebooks/       (exploration, cleaning, modeling)
  src/             (importable code)
  REPORT.md         (findings, honest limitations)
```

## Definition of Done
- Reproducible notebook that runs top to bottom
- Train/test split respected; no data leakage
- REPORT.md explains what the model can and cannot do
