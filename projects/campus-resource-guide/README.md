# Campus Resource Guide

A community site for NYC college students (BMCC/CCNY) listing campus resources: tutoring, food pantries, libraries, health services, clubs, and jobs.

## Phases
- **Week 4:** Static site — semantic HTML, responsive CSS, deployed on GitHub Pages.
- **Week 7:** Interactive — JavaScript search, category filters, and a section fed by a public API.

## Stack
Vanilla HTML, CSS, JavaScript. No frameworks — this project is for fundamentals.

## Definition of Done
- Mobile-first responsive layout
- Accessible (labels, alt text, keyboard navigation)
- Search filters resources by name and category
- Deployed and linked from the main README
