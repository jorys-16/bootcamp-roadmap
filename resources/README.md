## Electron (Desktop Apps)
- [Electron docs](https://www.electronjs.org/docs/latest) — start with the tutorial; it walks you from a first window to a packaged app.
- [Process model](https://www.electronjs.org/docs/latest/tutorial/process-model) — main, renderer, preload, utility processes.
- [IPC guide](https://www.electronjs.org/docs/latest/tutorial/ipc) — one-way and two-way communication patterns.
- [Security checklist](https://www.electronjs.org/docs/latest/tutorial/security) — read before shipping any Electron app.
- [Automated testing](https://www.electronjs.org/docs/latest/tutorial/automated-testing) — Playwright and WebdriverIO.
- [Electron Forge](https://www.electronforge.io/) — the officially recommended packaging and distribution tool.
- [Electron Releases](https://releases.electronjs.org/) — current stable versions with bundled Chromium and Node.js.
