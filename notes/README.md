# Notes

One file per topic, in your own words. Copying documentation is not note-taking.

## Suggested structure

```
notes/
  javascript-closures.md
  css-grid-vs-flexbox.md
  electron-process-model.md
  sql-joins.md
```

## Note template

```markdown
# Topic

## What it is (one sentence)

## Why it exists / what problem it solves

## How it works (in my own words, with a small example)

## Gotchas I hit

## Where I used it (project + week)
```

## Rules
- Write after you build something, not instead of building.
- Revisit old notes when you touch the topic again; update them.
- Link to the exact documentation page you used.
