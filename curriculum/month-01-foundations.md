# Month 1: Foundations (Weeks 1–4)

**Goal:** Understand how the web works, and build and publish your first static web page with clean HTML and CSS, version-controlled with Git.

## Week 1 — How the Web Works + Git
- How a browser request works: DNS, HTTP, client vs. server.
- Set up your environment (see [SETUP.md](../SETUP.md)).
- Git basics: `init`, `add`, `commit`, `push`; create your GitHub repo.
- Learn Markdown by writing your first notes in `notes/`.

## Week 2 — HTML
- Semantic HTML: headings, sections, lists, forms, tables.
- Accessibility fundamentals: labels, alt text, landmarks.
- Build the skeleton of the [Campus Resource Guide](../projects/campus-resource-guide/README.md): a page listing BMCC/CCNY student resources.

## Week 3 — CSS
- The box model, selectors, specificity, Flexbox and Grid.
- Responsive design basics and media queries.
- Style the Campus Resource Guide; add a mobile-friendly layout.

## Week 4 — Deploy + Review
- Publish the site with GitHub Pages.
- Run a self code review with [docs/code-review.md](../docs/code-review.md).
- Fill in [progress/week-04.md](../progress/week-04.md) and update [PROGRESS.md](../PROGRESS.md).

## Deliverables
- Deployed static Campus Resource Guide (HTML/CSS).
- All work committed to GitHub with clear commit messages.
