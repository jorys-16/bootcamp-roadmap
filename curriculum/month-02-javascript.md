# Month 2: JavaScript (Weeks 5–8)

**Goal:** Write modern JavaScript (ES6+), manipulate the DOM, handle events and async code, and make the Campus Resource Guide interactive.

## Week 5 — Language Fundamentals
- Variables (`let`/`const`), types, functions, arrays, objects.
- Control flow and loops; template literals, destructuring, spread.
- Exercises: `exercises/javascript/` sets 1–2.

## Week 6 — DOM and Events
- Selecting elements, creating/removing nodes, event listeners.
- Build interactive features on the Campus Resource Guide: search filter, category tabs.

## Week 7 — Async JavaScript
- The event loop, Promises, `async/await`, `fetch`.
- Consume a public API and render its data with error handling and loading states.

## Week 8 — Persistence + Mini-Project
- `localStorage` and `JSON.parse`/`stringify`.
- Start the [Student Planning Hub](../projects/student-planning-hub/README.md) (vanilla version): a to-do/planner app that persists data in the browser.

## Deliverables
- Interactive Campus Resource Guide with search + API-driven section.
- Vanilla Student Planning Hub v1 (add/complete/delete tasks, saved to localStorage).
