# Month 6: Python and AI (Weeks 21–24)

**Goal:** Get productive in Python, work with data using pandas, train a first machine-learning model, and call an LLM API from your own app.

## Week 21 — Python Fundamentals
- Syntax, data structures, virtual environments (`venv`), pip.
- Port two JavaScript exercises to Python; compare the mental models.

## Week 22 — Data with pandas
- DataFrames: loading, filtering, grouping, cleaning.
- NumPy arrays and vectorized operations.
- Start the [Data and ML Study](../projects/data-ml-study/README.md) project with a real dataset.

## Week 23 — Machine Learning Basics
- Supervised vs. unsupervised; train/test split; scikit-learn workflow.
- Train and evaluate a simple classifier; avoid overfitting; read metrics honestly.

## Week 24 — LLM APIs
- Call an LLM API (OpenAI, Anthropic, or Perplexity) from Python.
- Prompting basics, token costs, streaming responses.
- Optional stretch: wire a small AI feature into the Student Planning Hub.

## Deliverables
- Cleaned dataset + analysis notebook in `projects/data-ml-study/`.
- A trained model with an honest evaluation write-up.
- A script that calls an LLM API and handles errors.
