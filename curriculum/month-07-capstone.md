# Month 7: Capstone (Weeks 25–28)

**Goal:** Ship one complete project end to end: a deployed full-stack application with tests, CI, and a packaged desktop client, plus a portfolio-ready demo.

## Week 25 — Definition and Design
- Pick the capstone scope (extend the Student Planning Hub into a full product, or something new).
- Write a one-page spec: problem, users, features, and what you will NOT build.
- Record key choices in [docs/decisions.md](../docs/decisions.md).

## Week 26 — Build Core Features
- Frontend (React + TypeScript), backend (Express + Postgres), desktop client (Electron) as needed.
- Commit early and often; keep the CI pipeline green.

## Week 27 — Harden
- Tests for every critical path; security review against the Electron security checklist.
- Error handling, loading states, accessibility pass.
- Deploy everything; package the installer.

## Week 28 — Demo and Portfolio
- Record a 3–5 minute demo; polish the README with screenshots and architecture diagram.
- Update [docs/demo-checklist.md](../docs/demo-checklist.md) and run through it.
- Write a retrospective in `notes/`: what worked, what you'd do differently.
- Update your resume and LinkedIn with the capstone.

## Deliverables
- Deployed, tested capstone with CI and a packaged desktop client.
- Demo video + polished repository README.
- Retrospective notes.
