# Demo Checklist (Capstone, Week 28)

Use for the recorded demo and any live presentation.

## Before recording
- [ ] Fresh clone → install → run works (someone else tested it, not you)
- [ ] Production data seeded; no lorem ipsum or test names
- [ ] Demo script written: problem → solution → 3 key features → architecture → limitations

## During the demo
- [ ] Show the packaged desktop app (the real installer, not `npm start`)
- [ ] Show one E2E test running — prove it's tested, not just styled
- [ ] Show the deployed URL working
- [ ] Mention Electron security defaults you kept enabled (context isolation, sandbox)
- [ ] Name one thing that broke and how you debugged it

## After
- [ ] Upload to GitHub with tagged release and installer artifact
- [ ] README: screenshots, architecture diagram, setup steps
- [ ] Add to resume and LinkedIn; link the demo video
