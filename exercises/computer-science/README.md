# Computer Science Practice (ongoing)

One problem per week, any week, all 28 weeks. Pick from:

- [LeetCode easy/medium](https://leetcode.com/problemset/?difficulty=EASY) — arrays, strings, hashmaps
- [CS50 problem sets](https://cs50.harvard.edu/x/) — weeks 1-5 fit well
- [NeetCode roadmap](https://neetcode.io/roadmap) — arrays and hashing section first

## Rules
- 45 minutes max, then read the solution and re-implement it yourself.
- Write the complexity (time and space) in a comment above each solution.
- Log the problem and one insight in your weekly progress file.

This is the thread that keeps CS fundamentals alive alongside the project work.
