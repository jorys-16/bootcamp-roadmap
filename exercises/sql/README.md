# SQL Exercises

Use SQLBolt or a local PostgreSQL with a `students`, `courses`, `enrollments` schema you create.

1. Create the three tables with sensible keys; explain your FK choices in a comment.
2. All students enrolled in a course with more than 30 students.
3. Average grade per course, best course first.
4. Students not enrolled in anything (LEFT JOIN or NOT EXISTS — do both).
5. Add an index; measure the query difference with EXPLAIN ANALYZE and note it.

## Completion criteria
- [ ] Queries committed as .sql files
- [ ] Notes: what EXPLAIN ANALYZE showed before/after the index
