# Exercises

Practice files organized by topic. Each exercise lives in its own folder with a `README.md` describing the task, and your solution alongside it.

## Structure

```
exercises/
  javascript/       (Month 2)
  computer-science/ (ongoing)
  sql/              (Month 4)
  python/           (Month 6)
  electron/         (Month 3)
```

## Rules
- Attempt each exercise without looking at the solution first.
- Write your own solution even if you find a better one afterward; note the difference in the README.
- Keep every solution committed — they show growth over time.
